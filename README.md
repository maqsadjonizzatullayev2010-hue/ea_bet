# eFootball P2P Betting Telegram Bot

## O'rnatish va Ishga tushirish (Installation & Run)

1. **Paketlarni o'rnatish:**
   ```bash
   npm install
   ```

2. **`.env` faylini sozlash:**
   `.env.example` faylining nomini `.env` deb o'zgartiring va o'z ma'lumotlaringizni kiriting:
   - `BOT_TOKEN`: BotFather'dan olingan token.
   - `MONGODB_URI`: MongoDB Atlas ulanish manzili.
   - `ADMIN_TELEGRAM_ID`: Sizning Telegram ID raqamingiz.

3. **Botni ishga tushirish:**
   ```bash
   npm start
   ```
